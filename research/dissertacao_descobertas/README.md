# Descobertas Experimentais para Dissertacao

Esta pasta registra descobertas com ganho empirico observado e resultados negativos uteis dos experimentos de Fortaleza.

Regra de uso:
- registrar a hipotese testada;
- indicar o artefato ou script usado;
- comparar contra baseline simples;
- guardar numeros suficientes para futura redacao da dissertacao;
- separar ganho real de resultado negativo util;
- evitar conclusao metodologica antes de ganho real replicavel.
