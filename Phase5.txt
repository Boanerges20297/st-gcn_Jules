  📑 Plano de Operação Phase 5 (DeepSTGAT-Massive)

  1. Status Atual Onde estamos
    Arquitetura Criamos o DeepSTGAT (Phase 4), uma rede profunda com Atenção Temporal Multi-Head e Vetorização via
     Einsum. Ela é eficiente e já provou que aprende (atingiu 23% em apenas 180 dias).
    O Gargalo Descobrimos que o modelo gripa (overfitting) porque tem muitos neurônios para pouca história (apenas
     180 dias).
    A Descoberta O banco de dados bruto (dataraw) tem 1001 dias de história (desde 2022). Usar tudo isso é o segredo
     para os 60% de previsibilidade.
    O Obstáculo Tentar carregar 1000 dias de uma vez em um tensor único (TensorDataset) consome muita RAM e causou o
     fechamento do processo.

  ---

  2. O Plano de Ação (A ser executado no seu Core i5)

  Passo 1 Otimização do Dataset (Lazy Loading)
  Em vez de criar um tensor gigante de 1000 dias antes de começar, vamos alterar o código para que o Python leia os
  dados do tensor original apenas no momento de cada batch. Isso mantém o uso de RAM constante em torno de 2-4GB,
  independente do tempo total de histórico.

  Passo 2 Treinamento de Longa Duração
  Configuraremos o motor de treino para 100 épocas. Com 1000 dias, cada época no seu i5 deve levar entre 5 a 8 minutos.
  O treino completo levará algumas horas, mas a precisão subirá de forma muito mais robusta.

  Passo 3 Ativação da Hybrid Ranking Loss
  Manteremos a perda híbrida que foca em rankear bairros (quais são os mais perigosos hoje) em vez de apenas contar
  mortes.

  3. Scripts Necessários (Vou criá-los agora para você)

  Vou atualizar o seu Phase4train_v4.py para esta versão de Escala Massiva.

  Alterações que farei no código
   1. `LazyCrimeDataset` Uma classe que fatia os 1000 dias em janelas de 30 dias em tempo real.
   2. `NUM_WORKERS` Configurado para usar as threads do seu i5 para carregar dados enquanto a CPU processa a rede.
   3. `Memory Pining` Ativado para acelerar a transferência de dados.
